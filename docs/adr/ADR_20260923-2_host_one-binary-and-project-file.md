# ADR_20260923-2_host — Один бинарник и файл проекта `*.semaps`

Статус: **принято**. Уточняет следствия [`ADR_20260923_host_workspace-tool-source-roots`](ADR_20260923_host_workspace-tool-source-roots.md): три корня остаются, меняется, откуда берётся первый и где записаны два других.

> В контексте **ежедневного запуска редактора на своём проекте**, столкнувшись с тем,
> что **запуск требовал перейти в папку хоста, иметь Go и указать два пути руками**,
> мы решили:
> 1. **`app/` и `defaults/` вшиваются в бинарник (`go:embed`).** Инструмент — один
>    файл `semaps.exe`, ставится `install.cmd` в PATH.
> 2. **Окружение проекта — в файле `<имя>.semaps` в корне проекта**: где workspace,
>    где код, какой порт. Папка файла — корень проекта, пути в нём относительные.
>    Файл ассоциирован с `semaps.exe`: Enter или двойной клик открывает проект.
> 3. **`semaps` без аргументов ищет `*.semaps` вверх от текущей папки**; без файла —
>    первый `catalog.json` / `docs/diagrams/catalog.json`, корень кода — ближайший `.git`.
> 4. **Занятый порт не ошибка:** берётся следующий свободный — несколько проектов
>    могут быть открыты одновременно.
> 5. **Сервер уходит в своё окно консоли** (`--here` — остаться), вызвавший —
>    файловый менеджер, консоль — сразу свободен. Повторное открытие того же
>    проекта находит работающий сервер по `/api/info` и только открывает браузер.

## Отвергнуто

- **Только автопоиск без файла.** Работает на стандартной раскладке, но окружение
  (порт, нестандартный корень кода) тогда живёт в аргументах, которые каждый раз
  набирают руками. Файл делает проект самоописанным — как файл проекта у агента.
- **JSON вместо плоского YAML.** Файл пишет человек; комментарии нужны. Полный YAML
  не нужен: ключи плоские, парсер — двадцать строк без зависимостей.
- **Раздавать `app/` с диска рядом с бинарником.** Бинарник и бандл расходятся
  по версиям при копировании; один файл не может разойтись сам с собой.

## Следствия

- После `npm run build:app` или правки `defaults/` хост надо переустановить.
- Неизвестный ключ в `.semaps` — ошибка, а не молчание: опечатка в `workspace`
  иначе тихо открыла бы не тот каталог.
- Вложенные секции (например, настройки извлекателей) потребуют настоящего YAML —
  это отдельное решение.
