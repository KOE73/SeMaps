# ADR_20260923_host — Три корня хоста: инструмент, workspace, исходники

Статус: **принято**

> В контексте **выноса редактора схем в отдельный репозиторий SeMaps**,
> столкнувшись с тем, что **прежний сервер `server.go` раздавал всё из
> своей текущей папки — и собранный редактор (`app/`), и модели, и общие стили —
> а корень исходников задавался относительным `../../`**, так что инструмент и
> данные одного проекта были склеены,
> мы решили:
> 1. **Хост принимает два явных корня:** `--workspace` (модели; единственное
>    место, куда пишет `/api/save`) и `--source-root` (код для `codeRef`, только
>    чтение; по умолчанию — workspace).
> 2. **Бандл редактора `app/` отдаётся из папки инструмента**, а не из workspace.
>    Проект-потребитель хранит только workspace — без Node, без Go, без сборки.
> 3. **`styles.json`, `templates.json`, `content/` — умолчания инструмента**
>    (`host/defaults/`) с переопределением в workspace: есть файл в workspace —
>    отдаётся он, нет — умолчание. Запись всегда в workspace, так что первое
>    сохранение умолчания превращает его в переопределение; сами умолчания хост
>    не пишет никогда.
> 4. **Из умолчаний стилей убраны стили конкретных проектов** (`domain.*`,
>    зоны, названные по подсистемам одного продукта) — остались общие цветовые
>    зоны и стили видов сущностей.

## Отвергнуто

- **Копировать `app/` в каждый workspace**, как было раньше. Каждое обновление
  редактора — коммит с бандлом в каждом проекте-потребителе, и версии редактора
  разъезжаются между проектами.
- **Слияние стилей по ключам** (умолчание + дописанные в workspace стили). Нужен
  второй источник истины и правила конфликта; редактор сохраняет файл целиком.
  Переопределение — целым файлом.
- **Один флаг `--root` на всё.** Модели и код у потребителя лежат в разных местах
  (`docs/diagrams/` против корня репозитория), а запись в дерево исходников
  хосту не нужна и опасна.

## Следствия

- Под `go run` исполняемый файл лежит во временной папке, поэтому папка
  инструмента — рядом с бинарником, если там есть `app/`, иначе текущий каталог
  (`run.cmd` переходит в `host/`).
- Проект, у которого до сих пор лежал свой `styles.json`, продолжает
  видеть ровно его: это и есть переопределение.
