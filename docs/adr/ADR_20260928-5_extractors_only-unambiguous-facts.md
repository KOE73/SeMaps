# ADR_20260928-5_extractors — В графе только однозначные факты, эвристик нет

Статус: **принято**. Дополняет [`EXTRACTOR.md`](../EXTRACTOR.md) §3 («разрешённые символы, а не
текст») и [`ADR_20260928-4`](ADR_20260928-4_extractors_methods-and-calls.md).

## Контекст

Граф не видит того, что решается при выполнении: создание через отражение, получение из
контейнера зависимостей, вызов делегата. Каждое такое место можно «достроить» догадкой: рядом с
`Activator.CreateInstance` стоит `typeof(ImageRunner<,,,>)` — значит, создаётся `ImageRunner`;
`services.AddSingleton<IRunner, ImageRunner>()` — значит, `IRunner` это `ImageRunner`.

Первое верно для простого кода и неверно в общем случае. Второе — знание об одной библиотеке из
многих: контейнеров много, у каждого свои методы.

## Решение

1. **Факт попадает в граф, только если он однозначно следует из языка.** Разрешение имён —
   смысловой моделью компилятора, не текстом.
2. **Эвристик нет.** Извлекатель не угадывает цель, не связывает два места кода по соседству, не
   выводит намерение.
3. **Знания о библиотеках нет.** Извлекатель не знает контейнеров зависимостей, сериализаторов,
   каркасов. Исключение — одно, и с натяжкой: **базовая библиотека платформы** (для .NET —
   отражение из `System` и `System.Reflection`). Список её вызовов, которые извлекатель узнаёт,
   — короткий, в одном месте кода, и описан в `docs/extractors/<язык>.md`.
4. **О слепом месте граф говорит, что оно есть, и не говорит, что в нём.** Метод, в котором есть
   динамическое создание или вызов через отражение, получает отметку: вид и строка. Цели у
   отметки нет.
5. **Выводы делает читатель графа** — человек или агент, — у которого перед глазами факты и код.

## Отвергнуто

- **Связь с вероятной целью** (`typeof` рядом с `Activator.CreateInstance`). Догадка.
- **Связи контейнера зависимостей** (`AddSingleton`, `GetService`). Знание о библиотеке; у
  другого контейнера другие имена; регистрация сканированием и из настроек не видна вовсе.
- **Настраиваемые списки «узнаваемых» библиотек.** Тот же путь, только длиннее.
