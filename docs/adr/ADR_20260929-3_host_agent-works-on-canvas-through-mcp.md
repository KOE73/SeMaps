# ADR_20260929-3_host — Агент работает с холстом только через MCP

Статус: **принято**. Заменяет подход [`ADR_20260924_contract_agent-lays-out-views-on-request`](ADR_20260924_contract_agent-lays-out-views-on-request.md)
в части «агент читает файловый формат вида и пишет геометрию JSON-ом»; правило «только по просьбе
человека» остаётся. Сам ADR не менялся.

## Контекст

`docs/LAYOUT.md` был написан для агента, который правит JSON вида напрямую: форматы, координаты,
размеры, порядок работы. С тех пор модель принадлежит хосту (`ADR_20260925_host_model-owned-by-host`),
а геометрию агент меняет инструментами MCP (`move_elements`, `resize_elements`, `set_zone`, …),
результат сразу виден в открытом редакторе. Файловая инструкция устарела и толкала агента к
прямой правке файлов, минуя общую рабочую модель.

## Решение

1. **Файловые инструкции для агента убраны из живых документов** — `LAYOUT.md` перенесён в
   `docs/archive/`. Формат файла остаётся в `CONTRACT.md`; работа с видом описана инструментом
   `layout_guide` (Markdown, без JSON-формата): как смотреть вид, что делает каждый инструмент,
   порядок «посмотреть на образец → решить → применить шагами → проверить → сказать, что не
   сохранено», `requestedByHuman`.
2. **Числа холста — в одном файле данных `canvas.json`** (сетка, размеры узла и зоны, заголовок и
   отступ зоны, зазоры). Его отдаёт хост как `styles.json` (файл рабочего пространства побеждает),
   читают хост (`get_view`, `layout_guide`) и редактор; своих копий чисел нет. Хост **не**
   привязывает к сетке: сетка — привычка редактора, агент ставит на кратные шагу сами.
3. **`get_view` начинает ответ описанием холста** (единицы, направление осей, сетка, размеры по
   умолчанию и минимальные, заголовок и отступ зоны, зазоры).
4. **Глаза агента — `render_view`**: PNG вида, зоны или прямоугольника из открытого редактора
   (несохранённое состояние) и список проблем, вычисленный настоящим маршрутизатором и измерением
   текста редактора: перекрытия, обрезанные подписи и строки, линии через блоки, пересечения линий,
   узлы вне своей зоны. Без открытого редактора — ошибка с просьбой открыть вид.
5. **`create_view` и `create_project`** — только с `requestedByHuman: true`, когда человек прямо
   попросил новый вид или проект.

## Что отвергнуто

- Держать `LAYOUT.md` живым «на случай» — два источника правды о холсте и подсказка обойти MCP.
- Привязка к сетке на хосте — молчаливо меняет то, что попросил агент; сетка остаётся делом
  редактора.
- Рендерить PNG на хосте — у хоста нет настоящего маршрутизатора и измерения текста редактора;
  картинка разошлась бы с тем, что видит человек.
