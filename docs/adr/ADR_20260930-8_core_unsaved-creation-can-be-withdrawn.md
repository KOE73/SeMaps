# ADR_20260930-8_core — Несохранённое создание можно отозвать

Статус: **принято**. Уточняет правило «запись реестра не удаляется» (`CONTRACT.md` §9, `API.md` §3.4): оно
говорит о сохранённом. Дополняет [`ADR_20260930-7`](ADR_20260930-7_contract_view-edges-are-an-overlay.md) §3.

## Контекст

Редактор отправляет операции в общую рабочую модель хоста после каждого действия, а не при сохранении. Линия,
нарисованная человеком, заводит связь `origin: authored` в реестре (`ADR_20260930-7`); нарисованный блок — сущность.
Отмена такого действия сегодня ничего не может вернуть: хост отклоняет `value: null` для `relation` и `entity`, и
случайно проведённая и тут же отменённая линия остаётся в реестре — скрытой на этом виде и видимой на каждом
другом, где стоят оба её конца.

## Решение

1. **Запись реестра, созданная в несохранённом состоянии, отзывается** операцией с `value: null` (`relation`,
   `entity`). После отзыва её нет ни в рабочей модели, ни в списке несохранённого — как если бы её не создавали.
2. **Сохранённая запись не удаляется, как и раньше:** `null` для записи, которая есть в сохранённом реестре,
   отклоняется.
3. **Отзыв не оставляет висячих ссылок** — проверяется по состоянию после всего пакета: отозванная сущность не
   стоит ни на одном виде и не является концом связи; отозванная связь не названа ни в `edges`, ни в
   `relations.except` ни одного вида; её тексты отзываются тем же пакетом. Иначе пакет отклоняется.
4. **Редактор** при отмене действия, создавшего запись в этой сессии, отправляет отзыв вместе с обратными правками
   вида; повтор действия заводит запись с тем же id.
5. **MCP инструмента отзыва не получает:** агент не удаляет; человек отбрасывает несохранённое через `discard`.

## Отвергнуто

- **Держать операции создания в редакторе до сохранения.** Рабочая модель перестаёт быть общей: другой редактор и
  агент не видят линию, закрытие без сохранения теряет её молча.
- **Оставить как есть и скрывать через `except`.** Мусор в реестре от каждого промаха мышью, видимый на чужих видах.
- **Разрешить удалять сохранённые авторские записи.** На id ссылаются виды, тексты и связи; это другое решение.
