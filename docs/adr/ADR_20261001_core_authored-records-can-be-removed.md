# ADR_20261001_core — Авторскую запись можно удалить

Статус: **принято**. Уточняет правило «сохранённая запись реестра не удаляется» (`CONTRACT.md` §9 п. 7) и
пересматривает п. 5 и отвергнутый вариант «разрешить удалять сохранённые авторские записи»
[`ADR_20260930-8`](ADR_20260930-8_core_unsaved-creation-can-be-withdrawn.md).

## Контекст

Нарисованная человеком или заведённая агентом связь — запись реестра `origin: authored`
(`ADR_20260930-7`). После сохранения её нельзя убрать ни из редактора, ни через MCP: остаётся только скрыть
на виде, а на каждом другом виде с обоими концами она снова видна. Ошибочная линия или блок живут вечно, и
чем больше рисуют руками, тем больше такого мусора.

Правило «не удаляется» держит две вещи: стабильность ссылок (на `id` ссылаются виды, тексты, другие связи)
и память о коде (пропавший символ получает `missing`, а не исчезает). Для авторской записи вторая причина
не действует, а первую снимает удаление, которое тем же пакетом убирает все ссылки.

## Решение

1. **Сохранённую авторскую запись** (`entity` или `relation` с `origin: authored`) **можно удалить**:
   операция с `value: null`, как отзыв несохранённой. Запись из кода (`origin` не `authored`) по-прежнему
   не удаляется — `null` для неё отклоняется.
2. **Удаление не оставляет висячих ссылок** — то же правило пакета, что у отзыва (`ADR_20260930-8` п. 3):
   после пакета удалённая сущность не стоит ни на одном виде и не является концом связи, удалённая связь не
   названа ни в `edges`, ни в `relations.except`. Тексты под удалённым `id` уходят вместе с записью.
3. **Удаление — несохранённое изменение**, как любое другое: оно видно в списке несохранённого с автором,
   `Сохранить` пишет файлы без записи, `discard` возвращает её. Отдельного подтверждения нет — им служит
   сохранение.
4. **Одно правило для всех писателей** (`ADR_20260926`): пакет удаления — со всеми правками видов — строит
   ядро; редактор и MCP только зовут его.
5. **MCP получает инструмент `remove`** (пересматривает `ADR_20260930-8` п. 5): список `id` сущностей и
   связей за один вызов, только с `requestedByHuman`. Сущность, у которой остаются связи, удаляется вместе с
   ними лишь при явном разрешении (`cascade`); связь из кода у её конца делает удаление невозможным.
6. **Редактор** удаляет авторскую запись из реестра отдельной командой — не путать со «скрыть на этом виде».

## Отвергнуто

- **Подтверждать каждое удаление диалогом.** Подтверждение уже есть — сохранение; диалог на каждую запись
  делает массовую чистку неудобной и ничего не добавляет.
- **Помечать авторскую запись `missing` вместо удаления.** `missing` — факт о коде: символа не стало. У
  нарисованной записи кода нет; пометка оставила бы тот же мусор, только серым.
- **Удалять и записи из кода.** Следующая сверка вернёт их, а ссылки на ушедший символ должны жить.
