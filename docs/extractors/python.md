# Членские связи Python: соответствие типов признакам

**Статус:** извлекателя нет.

Черновой план соответствия типов Python признакам членских связей
(§2 [`ADR_20260924-4`](../adr/ADR_20260924-4_contract_member-relations-from-code.md)).

## Кратность и изменяемость коллекций

| Тип | Кратность | Изменяемость | Примечание |
|---|---|---|---|
| `list[T]` | `many` | `mutable` (?) | список; мутабельность неизвестна из типа |
| `List[T]` (typing) | `many` | `mutable` (?) | аннотация типа списка |
| `tuple[T, ...]` | `many` | `readonly` | кортеж переменной длины |
| `Sequence[T]` | `many` | `readonly` | интерфейс последовательности (readonly) |
| `Iterable[T]` | `many` | `readonly` | интерфейс итератора |
| `dict[K, V]` | `keyed` | `mutable` (?) | словарь; мутабельность неизвестна |
| `Dict[K, V]` (typing) | `keyed` | `mutable` (?) | аннотация типа словаря |
| `Mapping[K, V]` | `keyed` | `readonly` | интерфейс read-only словаря |
| `set[T]` | `many` | `mutable` (?) | множество; мутабельность неизвестна |
| `Set[T]` (typing) | `many` | `mutable` (?) | аннотация типа множества |
| `frozenset[T]` | `many` | `readonly` | неизменяемое множество |

**Замечание:** Python не различает мутабельность на уровне типа в большинстве случаев.
Только строго размеченные типы (`Mapping`, `Sequence`, `frozenset`) гарантируют readonly. Для остальных мутабельность неизвестна.

## Опциональность

| Тип | Кратность | Примечание |
|---|---|---|
| `T \| None` | `optional` | может быть None (PEP 604, Python 3.10+) |
| `Optional[T]` | `optional` | явно Optional из typing |
| `T` | `one` | обязательное значение |

**Замечание:** Python статически не проверяет None, но аннотация позволяет извлечь информацию.

## Отложенные типы

| Тип | Сигнатура пути | Примечание |
|---|---|---|
| `Coroutine[Any, Any, T]` | `result` | асинхронная корутина |
| `Awaitable[T]` | `result` | ожидаемый результат |
| `Generator[YieldType, SendType, ReturnType]` | `result` | генератор (сложный случай) |
| `Callable[..., T]` | `result` | вызываемое, возвращающее T |

**Замечание:** Python поддерживает async/await и генераторы; точное обозначение требует определения.

## Из кода не выводится (неизвестно)

| Что | Почему | Решение |
|---|---|---|
| Мутабельность (кроме явных readonly) | большинство типов мутабельны по умолчанию | ? |
| Наследование и полиморфизм | неявное в Python | авторская связь |
| Интерфейсы (Protocol) | неявная реализация | авторская связь |

## Маппинг kind и nativeKind

| kind | nativeKind | Примеры |
|---|---|---|
| `type` | `class` | класс |
| `interface` | `protocol` | Protocol (PEP 544) |
| `function` | `function` | функция на уровне модуля |
| `module` | `module` | модуль (.py файл) |
| `module` | `package` | пакет (__init__.py) |
| `value` | `constant` | константа (по конвенции) |
| `value` | `variable` | переменная на уровне модуля |
