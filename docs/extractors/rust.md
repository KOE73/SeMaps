# Членские связи Rust: соответствие типов признакам

**Статус:** извлекателя нет.

Черновой план соответствия типов Rust признакам членских связей
(§2 [`ADR_20260924-4`](../adr/ADR_20260924-4_contract_member-relations-from-code.md)).

## Кратность и изменяемость коллекций

| Тип | Кратность | Изменяемость | Примечание |
|---|---|---|---|
| `Vec<T>` | `many` | `mutable` (?) | вектор; мутабельность неизвестна из типа |
| `[T]` | `many` | `mutable` (?) | срез (неразмерный массив) |
| `[T; N]` | `many` | `mutable` (?) | массив фиксированного размера |
| `&[T]` | `many` | `readonly` | ссылка на срез (immutable по ссылке) |
| `&mut [T]` | `many` | `mutable` | изменяемая ссылка на срез |
| `HashMap<K, V>` | `keyed` | `mutable` (?) | словарь; мутабельность неизвестна |
| `BTreeMap<K, V>` | `keyed` | `mutable` (?) | упорядоченный словарь |
| `HashSet<T>` | `many` | `mutable` (?) | множество (неупорядоченное) |
| `BTreeSet<T>` | `many` | `mutable` (?) | множество (упорядоченное) |

**Замечание:** В Rust мутабельность — это свойство привязки (binding), а не типа.
`Vec<T>` и `&Vec<T>` имеют один тип, но разное владение. Извлекатель не может вывести мутабельность только из типа.

## Опциональность

| Тип | Кратность | Примечание |
|---|---|---|
| `Option<T>` | `optional` | может быть Some(T) или None |
| `T` | `one` | обязательное значение |

**Замечание:** `Option` явно обозначает nullable.

## Отложенные типы

| Тип | Сигнатура пути | Примечание |
|---|---|---|
| `impl Future<Output = T>` | `result` | асинхронное будущее |
| `fn() -> T` | `result` | функция, возвращающая T |

**Замечание:** `Box<T>`, `Arc<T>`, `Rc<T>` — не отложенные: это владение и разделение, объект
уже есть. Они прозрачны: слота не добавляют, признаки берутся у `T`.

## Из кода не выводится (неизвестно)

| Что | Почему | Решение |
|---|---|---|
| Мутабельность переменной | свойство привязки (binding), не типа | ? |
| Время жизни (lifetime) | генерики с жизненным циклом | авторская связь, если нужна явность |
| Trait-объекты и полиморфизм | динамическая диспетчеризация | авторская связь |

## Маппинг kind и nativeKind

| kind | nativeKind | Примеры |
|---|---|---|
| `type` | `struct` | структура |
| `type` | `enum` | перечисление |
| `type` | `union` | объединение (C-compatible) |
| `interface` | `trait` | трейт |
| `function` | `function` | функция |
| `function` | `impl` | метод реализации (impl block) |
| `module` | `module` | модуль |
| `module` | `crate` | крейт (пакет) |
| `value` | `const` | константа |
| `value` | `static` | статическая переменная |
