# IDEA_20260928-2_extractors — Вызовы по запросу, без хранения

Стоит на [`ADR_20260928`](../adr/ADR_20260928_host_live-code-graph.md) §6 и §7.

## Мысль

Факты описывают структуру: кто от кого наследует, кто кого держит и упоминает в сигнатурах.
Вопрос «кто вызывает X» — о потоке управления. Таких рёбер на порядки больше, они меняются с
каждой правкой, хранить их незачем. Но агенту этот вопрос нужен часто, и отвечать на него
чтением файлов дорого.

## Как это может выглядеть

Извлекатель получает режим запроса: не «выгрузи всё», а «ответь на один вопрос».

```
semaps-extract-<lang> query --callers <symbol> [--root … --include …]
semaps-extract-<lang> query --callees <symbol>
semaps-extract-<lang> query --references <symbol>
```

Ответ — список мест: символ, файл, строка. Хост отдаёт его агенту инструментом MCP и, по
желанию, странице графа как временные рёбра вокруг выбранного узла.

Движок для этого в извлекателях уже загружен: Roslyn и компилятор TypeScript умеют находить
ссылки с учётом типов.

## Что мешает

- Разовый запуск извлекателя C# — секунды на загрузку решения. Запрос имеет смысл, когда процесс
  уже живёт — то есть после режима наблюдения
  ([`PLAN_20260928-4`](../plans/PLAN_20260928-4_host_watch-sources.md), ступень 2).
- [`EXTRACTOR.md`](../EXTRACTOR.md) §2.2a прямо говорит: вызовы — не факты извлекателя. Запрос
  этого не нарушает (в факты вызовы не попадают), но формулировку придётся уточнить новым ADR.

## Рядом

- **Чужой сервер языка (LSP)** как источник вызовов для языков, где своего извлекателя нет.
- **Свой LSP-сервер** — в другую сторону: показать карту в IDE (контейнер и описание над
  классом, предупреждение «эта зависимость картой не разрешена»).

Обе — отдельные идеи, если до них дойдёт.
