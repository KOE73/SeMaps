# IDEA_20260928-3_core — Анализ влияния по модели

Стоит на [`ADR_20260928`](../adr/ADR_20260928_host_live-code-graph.md).

## Мысль

Инструменты графа кода отвечают на уровне символов: «изменил функцию — затронуты 14
вызывающих». У нас символы связаны с моделью, поэтому отвечать можно на уровне архитектуры:
какие сущности, контейнеры, виды и тексты задевает изменение.

## Примеры

**Изменённые файлы → карта.** В ветке изменён `host/journal.go`:

```
Затронуто: сущность Journal (контейнер Host)
От неё зависят: McpServer, SaveHandler
Виды, где она есть: «Поток сохранения», «Работа агента»
Тексты, которые могли устареть: описание Journal, связь Journal → Workspace
```

**Код ушёл от карты.** В коде появилась зависимость `Canvas → Store`; между контейнерами Editor
и Host связи на карте нет:

```
Новая зависимость в коде: Canvas → Store
На карте связь Editor → Host не объявлена
```

**Вопрос до правки.** «Что сломается, если изменить формат `.semaps`?» — список сущностей и
документов, а не сорок файлов из поиска.

## Из чего собирается

- изменённые файлы (`git diff --name-only`) → символы по `file` → сущности по `symbol`;
- соседи по графу — [`PLAN_20260928`](../plans/PLAN_20260928_host_graph-provider.md);
- виды, где сущность размещена, и тексты с их происхождением — уже в модели;
- принадлежность контейнеру — там же, шаг 2.

## Что надо решить, прежде чем планировать

- Что значит «разрешённая связь между контейнерами»: сейчас контракт этого не выражает,
  принадлежность — подсказка ([`CONTRACT.md`](../CONTRACT.md) §6).
- Где это живёт: команда `semaps impact` для CI, инструмент MCP, или обе.
- Точность без диапазонов строк — до файла; с ними
  ([`PLAN_20260928-3`](../plans/PLAN_20260928-3_extractors_code-positions.md)) — до символа.
