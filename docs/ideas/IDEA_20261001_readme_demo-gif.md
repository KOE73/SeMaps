расхождение.

## Что не сработало (2026-10-01)

движения нет, главное (агент пишет в карту, сверка с кодом) не показано, интерфейс на русском,
800×475 мелко, большие виды при «Вписать» не читаются.

## Как сделать

- Настоящая запись экрана, не склейка скриншотов; ширина от 1280.
- Английский интерфейс и английские имена карты.
- Сценарий: агент через MCP добавляет блок → он появляется на холсте → правка кода →
