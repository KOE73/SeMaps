## Выбор библиотеки

Выбрано: **sigma + graphology** (решение человека, 2026-09-28, по пробе шага 1).

| Пакет | Версия | Лицензия |
|---|---|---|
| `sigma` | 3.0.3 | MIT |
| `graphology` | 0.26.0 | MIT |
| `graphology-layout-forceatlas2` | 0.10.1 | MIT |
| `graphology-communities-louvain` | 2.0.2 | MIT |
| `graphology-layout-noverlap` | 0.4.2 | MIT |

Почему: подписи узлов и соседи узла — встроены; раскладки и сообщества — готовые пакеты над
одной моделью графа; силовая раскладка считается в фоновом потоке; сжатая сборка страницы пробы
— около 45 КБ.

Отвергнуто: `@cosmos.gl/graph` 3.4.2 (MIT). Нет подписей и списка соседей, раскладка — только
физика, сжатая сборка около 190 КБ; выигрыш в скорости первой отрисовки на наших объёмах не
нужен. Старое имя пакета `@cosmograph/cosmos` публикуется под CC-BY-NC-4.0 — не ставить.

## Шаги

### 1. Проба

**Сделано 2026-09-28**, вне репозитория, на фактах извлекателя TypeScript по `editor/src`
(836 символов, 731 ребро) и на наборе в десять раз больше (8360 и 7490).

| Набор | Библиотека | Первая отрисовка | Кадров/с при движении |
|---|---|---|---|
| обычный | sigma | 138 мс | 60 |
| обычный | cosmos.gl | 18 мс | 60 |
| ×10 | sigma | 374 мс | 60 |
| ×10 | cosmos.gl | 28 мс | 60 |

Что проба показала для следующих шагов:

- Силовая раскладка с настройками по умолчанию за 5 с не успокаивается: нужен свой признак
  остановки и настройка.
- Перед первой отрисовкой узлам нужны начальные координаты, иначе они лежат в одной точке.
- На снимке страницы sigma линии не различимы — проверить толщину и цвет рёбер на шаге 3.
- Страница cosmos.gl при повторном просмотре показала пустой экран; причина не выяснялась.
- Не проверено: дата последнего коммита в репозиториях библиотек; проба на графе из
  `GET /api/graph/{project}` и на NeuroModFlowNet.ONNX — адреса ещё не было.

### 2. Режим «Граф»

- `editor/src/app/graph.ts`, режим `graph` в `toolModes.ts`, адрес `/app/#graph`.
- Зависимости графа — только в сборке приложения, не в пакете холста (ADR-2, последствия).
  Загрузка по первому входу в режим.
- Строки интерфейса — в `editor/src/shell/strings.ts`.

### 3. Узлы и линии

- Размер узла — по числу связей. Цвет — по выбранному признаку: вид символа, контейнер,
  пространство имён, род узла.
- Род узла виден всегда: «только в коде» — серый, «только в модели» — контур без заливки.
- Линия: вид ребра — цвет; `via.cardinality` = `many`/`keyed` — толще; `via.deferred` — пунктир.
- Подписи — у крупных узлов и у выделенного с соседями.

### 4. Поведение

- Наведение: подсветка узла и соседей, остальное гаснет.
- Выбор: панель с именем, видом, файлом и строкой, сущностью, контейнерами; ссылки «открыть
  исходник» и «найти на диаграммах».
- Фильтры: виды рёбер, виды символов, видимость, род узла, контейнер.
- Поиск по имени.

### 5. Раскладки и группировка

Переключатель: силовая; по папкам; по пространствам имён; по сообществам связей; по
контейнерам модели. Смена раскладки — анимацией, выделение сохраняется.

Положения узлов в рабочую папку не пишутся (ADR-2 §3). Сохранять ли их на время сеанса в
браузере — решить по опыту.

### 6. Живое обновление

**Сделано.** По событию графа (план поставщика, шаг 5): `editor/src/app/graph.ts` держит
отдельный `EventSource` на `/api/events?project=<id>`, пока открыт режим «Граф» для этого
проекта; событие без `graph` игнорируется, с `graph` — вызывает перечитывание графа и
`GraphEngine.applyDiff` (`editor/src/app/graph/engine.ts`): добавленные узлы появляются рядом со
средним положением уже расставленных соседей (или у центра, с небольшим случайным смещением),
убранные исчезают, изменённые получают новые данные, остальные **остаются на местах**. Полная
перераскладка — только по кнопке. Подписка закрывается при уходе с режима (`leaveGraph`, через
новый `WorkbenchMode.leave`), смене проекта и перерисовке. События, пришедшие пока идёт
перечитывание, схлопываются в один следующий запрос. Выделение и камера сохраняются; если
выделенный узел пропал — сбрасываются панель и выделение. Короткое уведомление в панели
инструментов показывает, сколько узлов и рёбер добавилось/пропало.
