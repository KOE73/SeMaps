# Модификаторы оформления и правила применения

Статус: закрыт.

## Объём

Отдельные определения модификаторов и правил в общей рабочей модели workspace; каскад:
базовый/явный стиль → автоматические модификаторы → ручные модификаторы → локальный override.
Определения сохраняются кнопкой сохранения стилей; назначения остаются состоянием проекта/вида.
Автоматический результат вычисляется и не записывается в размещения.

## Порядок

1. Расширяемое дерево условий с каталогом полей/операций и строгой проверкой; структурная
   принадлежность сборке, namespace, библиотеки, свойства сущности/связи и концов связи.
2. Общая модель определений, CRUD, проверки ссылок, Save/Discard и вычисление с объяснением.
3. HTTP и MCP: каталог условий, CRUD, предпросмотр, объяснение и ручные назначения.
4. Модификаторы в панели стилей; отдельная панель правил; пропорциональный разделитель.
5. Контракт, API, проверки каскада, конфликтов, отсутствующих данных, двух редакторов и восстановления.

## Приёмка

Разные базовые стили класса/интерфейса сохраняются под одной палитрой. Новое размещение
автоматически получает палитру по данным сущности. Перемещение блока между нарисованными
контейнерами не меняет принадлежность сборке. Неизвестные поля, операции и ссылки отклоняются.
Порядок правил воспроизводим, ручное исключение и override видны в объяснении.
MCP и два UI показывают одно состояние без перезагрузки; сохранение/откат не меняют геометрию.
Разделитель сохраняет долю ширины при изменении ширины панели.

## Результат и проверка

Реализованы отдельные коллекции modifiers/styleRules, версионированный каталог полей,
all/any/not, строгая проверка, вычисляемый каскад и происхождение свойств. UI использует
общий хост: модификаторы в стилях, отдельные правила с конструктором и предпросмотром,
ручные назначения/исключения, переходы из панели изменений. MCP предоставляет 17 новых
инструментов. Контракт/API/ADOPTING обновлены; решение — ADR_20261008_contract_style-modifiers.

Проверено:

- `go test ./... -timeout 90s`, `go vet ./...` — успешно. Проверки включают разреженные шрифты,
  alpha/opacity, порядок, локальные override, структурные contains и концы связей, unknown/NOT,
  новое размещение после создания правил, конфликт revision, атомарный отказ, Save/Discard,
  восстановление журналов и скрытые сохранённые ссылки. Удаление с заменой и последующее
  перемещение сохраняют исходные списки модификаторов при откате и независимые назначения.
- `npm run check:model-sync`, `check:style-sync`, `check:host-session`, `check:style-extensions`
  — 20 + 7 + 8 + 7 случаев. `npm run build:app` включает typecheck; сборка успешна.
  Vite сообщает о большом размере основного chunk, как и раньше.
- Реальный HTTP MCP: каталог, CRUD, preview/explain, назначения и исключения, два SSE-клиента,
  переименование, сохранение и повторное открытие. Геометрия не меняется.
- Два открытых браузерных редактора: UI-создание палитры/правила; MCP-обновление и переименование
  меняют оба окна без перезагрузки; составное условие namespace+interface даёт одно совпадение;
  ручной акцент перекрывает автоматический; Save в UI очищает общую библиотеку изменений.
  После повторного открытия базовые стили и результат каскада сохранились.
- Разделитель проверен реальным перетаскиванием: доля 0.506 сохраняется при ширине панели
  579 → 499 px (список 290 → 249.6 px). Удалено старое CSS-ограничение 180 px на узкой панели;
  учтена ширина самого разделителя. Минимумы применяются только при доступном месте.
- Отдельный сохранённый пример проходит `semaps check` с exit 0. Исправлены обнаруженные в QA
  ошибки обновления вида с ID, отличным от имени файла, и потери его ID при инвалидировании SSE.
